# Whack-a-Mole Demo

Lightweight, dependency-free Whack-a-Mole mini game for the profile README makeover.

## Files
- `index.html` — playable demo with embedded CSS/JS (3x3 grid, score tracking, mobile-friendly controls)

## Run locally
Open `index.html` directly in any modern browser.

## Accessibility notes
- Score changes are announced via an `aria-live` region.
- All holes are keyboard-focusable buttons with touch-friendly hit areas.
